# Agent Note: 独立 Task 应用

Status: implemented

[English](2026-09-13-task-independent-application.md) | 中文

## 问题

可复用的 Task 后端需要服务未来 Web 和原生应用，同时不依赖其具体实现，也不修改原 Base 和 Web 应用。

## 决策

内置 Task Profile 组合 Base 与 Task App。Task App 挂载未修改的 Host WebServer、Task 专属运行时及 REST 网关。当前范围不含业务插件、Task Web UI 和原生客户端应用；不提供前端资源、自动打开浏览器或签发浏览器登录链接的命令，启动时输出 API 地址。默认旧 Task 组合迁移到新 bundle 列表，自定义组合保留。Base、Web App 和共享运行时源码保持不变。

业务插件拥有阶段、配置 schema 及可选检查和选项来源，每个 Cordis fiber 对应一个特殊任务，不提供浏览器代码。Draft 2020-12 校验只允许本地引用，schema 版本变化需要显式迁移，每个执行保存 forms 快照，普通执行继承父执行配置与 forms。已有业务等待保留其持久化 schema 和版本。工具审批和模型提问持久化，响应必须匹配仍在准入执行中的等待者、输入版本和有效期。重启撤销中断的运行时请求，旧批准不能授权新工具执行。

普通任务正在取消或清理阻塞时，关联同一业务键的发现会记录来源，但不投递新输入或推进已观察值。

REST 命令保留引擎原子回执。Task 日志 SSE 与 Session 消息 SSE 使用独立游标及有界分页，读取不激活 Agent。Session 持久化尚不可用时，会话记录和附件读取返回 `409 session_unavailable`，客户端可对正在准备的 Run 重试。附件使用有界 multipart 请求、不可变摘要文件和主体范围内的持久重试回执，下载检查执行归属并支持单个字节范围。浏览器认证包括登录交换、签名 Cookie、CSRF 和撤销。本地管理 Profile 通过共享凭据文档的跨进程文件锁签发可撤销的 API Bearer 凭据。浏览器认证保留为未来集成使用的 API 能力；后端不提供登录页面。共享凭据引用提供状态及只写替换接口，响应和日志不包含值。

管理备份要求 Task 宿主已停止，并获取与引擎相同的独占锁，通过 SQLite backup API 复制数据库并校验全部文件。恢复在发布到空目录前校验清单、字节和数据库，重定位保留的 preset 并更新 Task 事件流身份，不回滚凭据和外部业务操作。当前实现采用离线一致性屏障，不提供运行中备份，不安装系统后台服务。

卸载与资源获取保留持久意图，因为进程可能在本地提交与外部确认之间退出。恢复从保存的入口元数据加载未改变的已安装代码，并在复用资源句柄前重新核实。文件系统适配器验证所有权，并在删除前保留工作树改动。必须在卸载完成后移除包；入口摘要可以检测替换，但不会保存已移除的包及其依赖。

调度器就绪同时取决于启动器完成和 Task 恢复。只有恢复成功结束后才创建定时器；恢复期间关闭会阻止延迟创建，并等待恢复 Promise 结束。恢复失败保持可观测，且不接纳执行。

## 验证

聚焦引擎测试覆盖 Schema 迁移、表单校验、持久审批、取消与等待过期。Profile 测试覆盖独立派发、同一 Session 重启恢复、HTTP 认证与回执、附件重放与范围下载及只读拒绝、Session SSE 和管理操作。源码与构建产物的 Profile 测试验证没有前端文件时 API 仍可运行，且根路径和索引页返回 404。源码隔离检查拒绝受保护原模块的改动。

## 考虑过的替代方案

将 Task 前端随包发布会让后端验收依赖展示层工作；Cordis Task 面板还会引入 Web 应用依赖。业务专属组件会将每个插件与前端版本绑定。后端保留扩展机制和公共 API，未来共用客户端作为独立范围实施。

## 影响

Session 订阅传输持久化消息。附件下载会验证指定事件与内容块属于任务自有 Session 中可见的原始消息。仅供模型使用的替换不能授予附件访问权限。插件必须在取消后结束异步检查。文件系统备份通过原子重命名发布；发布成功不保证超出文件系统能力的断电持久性。旧的内容寻址文件没有自动保留或垃圾回收策略。

调度增加可配置且有上限的等待优先级，同分时按创建时间排序。通知持久保存重放确认，并提供稳定身份供提供者去重。可配置的取消及停机期限记录超时但不释放仍在使用的资源；清理超时会中止插件信号，并保留阻塞资源等待修复。
