# Agent Note: 面向 Web 客户端的 Task 后端能力

Status: implemented

[English](2026-10-03-task-web-client-capabilities.md) | 中文

## 问题

[Task Web 原型](../../../../design/task-web/README.zh.md)需要的部分事实和操作，Task 网关此前没有公开。浏览器没有受支持的方式获取登录凭据。业务等待的提示内容不是字符串时会丢失结构，工具审批不指明待批准的工具调用，Agent 提问被压平成一行标题。待处理列表必须逐个查询每个执行。清理失败的 Run 只显示 `blocked`，而通过取消重试清理会把已记录的成功改写为 `cancelled`。表单无法让客户端识别凭据字段、动态选项或多行文本，因此无法列出凭据引用。补充输入没有声明格式，执行历史不能按派发来源或多个状态筛选，被调度器暂停的定义也不说明原因。

## 决策

Task profile 仍不提供前端。`dsh --profile task --launch-link` 通过与网关相同的凭据存储签发一次性浏览器登录凭据，并输出 `{ url, expiresAt }`；凭据位于 `--port` 对应宿主或管理配置 `publicOrigin` 的 URL 片段中。网关会重新读取共享凭据文档，因此正在运行的网关也能接受该凭据；浏览器将其提交到 `/auth/exchange`。登录交换和 `GET /auth/session` 同时返回会话过期时间。

业务等待的提示内容可以是 `{ title, body, attachments }`：`body` 为 Markdown，`attachments` 为 Run 附件 ID。等待记录创建时间。运行时工具审批保留发起请求的 `callId`，Agent 提问保留每个问题的标题、补充说明、选择方式和选项说明。每条交互 DTO 都标明所属 Run，`GET /interactions` 按创建顺序列出所有执行中等待回复的业务确认、工具审批和提问。

终态结算在清理开始前将决定记录为 Run 的 `outcome`。清理失败后，Run 保持 `blocked` 并保留该终态。`POST /runs/{runId}/cleanup`（命令 `cleanup`）只重试受阻的清理；取消此类 Run 也使用同一记录，因此重试后的 Run 以最初的成功、失败或取消结论结束。

插件表单只接受一个 Task 注解 `x-dsh-widget`，取值为 `textarea`、`credential` 和 `options`；注册时拒绝其他 `x-dsh-` 键，凭据控件要求字符串值且必须是有效的凭据引用名。`GET /credentials` 列出已安装定义当前配置引用的凭据及不含值的状态。可选的 `forms.supplement` schema 按每个 Run 的快照校验补充输入，定义和 Run 都会公开它。

Run 公开调度时刻 `occurrence`，包括合并补跑的日历范围；执行查询接受逗号分隔的状态和 `parentRunId`。调度器将阻塞原因保存在定义上，重新启用时清除；定义公开 `availability`，由安装状态、启用状态、该原因和最近一次退役共同推导。目录中的 preset 附带显示名称和说明。Task 数据库 schema 版本 9 增加来源与等待交互索引；此前写入的记录无需改写即可读取。

## 备选方案

**现在就由 Task 宿主提供 Web 客户端。** 随 Web 实现一同推迟：没有构建产物的托管插件只能提供测试样例，而客户端部署到网关源后，登录凭据无需任何改动即可使用。

**由管理命令打开浏览器。** 在 profile 提供客户端之前不采用：打开链接只会得到 404 页面。输出链接还可用于代理后面的开发客户端，其源配置为 `publicOrigin`。

**只通过取消重试清理。** 不作为唯一操作：取消正在运行的 Run 必须保持原有含义，而客户端需要一个在清理未受阻时明确失败的操作。取消清理受阻的 Run 仍保留记录的终态，因为二者走同一个结算流程。

**公开阶段检查点或阶段状态。** 不采用：检查点是插件私有数据，可能包含业务内容。客户端使用状态、原因、终态、等待和会话记录。

**由客户端汇总交互。** 不采用：待处理列表需要为每个未结束执行发一次请求，并且仍会漏掉 Run 处于 `running` 时发起的审批。

**插件提供表单组件或开放式提示。** 不采用：插件不提供前端代码，无界的提示词表无法在注册时校验。凭据引用也不根据字段名推断。

## 影响

客户端可以基于公开数据构建登录、待处理、清理修复、凭据和派发关系界面。插件 schema 中所有 `x-dsh-` 键均为保留键，包括属性名以及 `default`、`const` 或 `enum` 取值中的对象键。本变更之前已进入清理受阻的 Run 在下次结算前没有记录的终态，其等待使用 Run 更新时间作为创建时间。为错误端口或源输出的登录链接无法完成交换。`TaskRunQuery` 中的 `status` 改为列表，DTO 新增字段依赖客户端忽略未知字段。
