访问令牌

原生客户端和脚本使用设备令牌（Bearer）访问任务接口。令牌只显示一次，服务端只保存摘要；签发与撤销在本机终端完成：

dsh --profile task --token-create
dsh --profile task --token-revoke <设备 ID>

浏览器通过启动链接登录，不需要设备令牌；请不要把设备令牌粘贴到网页中。
